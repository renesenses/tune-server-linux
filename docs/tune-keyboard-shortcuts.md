# Tune — Raccourcis Clavier

*Accessibilité — Guide de référence rapide*

---

## Lecture

| Raccourci | Action |
|-----------|--------|
| **Espace** | Lecture / Pause |
| **N** | Piste suivante |
| **P** | Piste précédente |

## Navigation dans la piste

| Raccourci | Action |
|-----------|--------|
| **Flèche droite** | Avancer de 10 secondes |
| **Flèche gauche** | Reculer de 10 secondes |
| **Shift + Flèche droite** | Piste suivante |
| **Shift + Flèche gauche** | Piste précédente |

## Volume

| Raccourci | Action |
|-----------|--------|
| **Flèche haut** | Augmenter le volume (+5%) |
| **Flèche bas** | Diminuer le volume (-5%) |
| **M** | Couper / Rétablir le son (mute) |

---

*Ces raccourcis fonctionnent dans l'interface web de Tune (http://&lt;serveur&gt;:8888).
Ils sont désactivés lorsqu'un champ de saisie est actif (recherche, édition, etc.).*

*Une zone audio doit être sélectionnée pour que les raccourcis fonctionnent.*
