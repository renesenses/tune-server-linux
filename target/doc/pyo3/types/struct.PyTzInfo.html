Bindings for datetime.tzinfo.

Values of this type are accessed via PyO3’s smart pointers, e.g. as Py<PyTzInfo> or Bound<'py, PyTzInfo>.

This is an abstract base class, the primary implementations are datetime.timezone and the zoneinfo module.

The constructors PyTzInfo::utc, PyTzInfo::fixed_offset and PyTzInfo::timezone create these concrete subclasses.
